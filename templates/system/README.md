# 内置模板（system）

这是 Obsidian Projects 的内置模板目录。

## 文件列表

- `issue-template.md`
- `task-template.md`
- `project-template.md`
- `team-template.md`
- `product-template.md`
- `member-template.md`
- `feature-unit-template.md`

## 使用方式

- 在插件设置中配置：
  - Template root directory（默认 `templates/system`）
  - Default template type
  - 每个模板类型对应的文件名
- 创建笔记时，插件会按类型映射自动选择模板。
